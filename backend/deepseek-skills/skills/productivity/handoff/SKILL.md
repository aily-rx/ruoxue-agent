# 会话交接

## 目的

将当前对话的关键上下文压缩成一份交接文档，使得：
- 下一个会话的新 Agent 能在最短时间内理解当前进度
- 不需要重读全部对话历史
- 包含"现在做到哪了"和"下一步做什么"

## 交接文档模板

```markdown
# 会话交接 — [日期] [主题]

## 1. 当前状态
- 项目/功能当前处于什么阶段
- 已完成的工作清单
- 待完成的工作清单

## 2. 关键决策
- 做了什么选择？为什么？
- 放弃了什么方案？为什么？

## 3. 当前阻塞
- 卡在什么地方？
- 需要什么信息/资源才能继续？

## 4. 下一步
- 具体的下一步行动（可执行，不是模糊的"继续开发"）

## 5. 关键文件
- 修改了哪些文件
- 哪些文件需要重点关注

## 6. 注意事项
- 已知的坑
- 特殊的本地配置
- 依赖的外部服务状态
```

## 反模式

- **只写"继续开发"** — 下一轮的 Agent 不知道从哪开始，等于没交接
- **省略失败记录** — 试过的错误方案不记，下一轮还会重蹈覆辙
- **过于简略** — "在 agent_graph.py 里加了个功能"不如"在 agent_graph.py 的 run_agent_stream() 中加了 Layer 4 skill_context"
- **不提阻塞项** — 卡住的信息不说，下一轮 Agent 也会卡住

## 步骤

1. **精炼，不省略** — 去掉对话中的试错过程，保留结论和决策
2. **可执行** — "下一步"必须是具体动作，不是模糊方向
3. **包含失败记录** — 试过但失败的方案也要记录，避免下一轮重蹈覆辙
4. **标注数据源** — 如果依赖外部数据或配置，写明路径和状态

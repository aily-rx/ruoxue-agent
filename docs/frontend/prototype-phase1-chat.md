# Phase 1 — 聊天界面 ASCII 原型

> 版本: v1.0 | 日期: 2026-07-24 | 对应: Phase 1 文字聊天机器人

---

## 一、组件树

```
<div #app>                              <- 根容器 (100vw x 100dvh, flex column)
├── <header #app-header>                <- 顶栏
│   ├── <span .logo>Ruoxue</span>      <- Logo 文字
│   └── <span .status>                <- 连接状态指示
├── <main #chat-container>              <- 消息区 (flex:1, overflow-y:auto)
│   ├── <div .empty-state>             <- 空状态占位 (无消息时显示)
│   ├── <div .message.user>            <- 用户消息 (右侧)
│   │   ├── <div .bubble>             <- 气泡
│   │   └── <span .time>              <- 时间戳
│   ├── <div .message.ai>              <- AI 消息 (左侧)
│   │   ├── <div .avatar>             <- 头像占位 (Phase 3 升级为 Live2D)
│   │   ├── <div .bubble>             <- 气泡
│   │   │   ├── <span .cursor>        <- 闪烁光标 (流式输出时)
│   │   │   └── <span .text>          <- 文字内容
│   │   └── <span .time>              <- 时间戳
│   └── <div .error-state>            <- 错误状态 (连接失败时)
├── <div #quick-replies>               <- 快捷回复 (可选)
│   ├── <button>你好</button>
│   ├── <button>今天天气怎么样</button>
│   └── <button>你能做什么</button>
└── <footer #input-bar>                <- 输入栏
    ├── <textarea #input>              <- 输入框 (自适应高度)
    └── <button #send-btn>            <- 发送按钮
```

## 三、PC 端 — 对话中

有历史消息 + AI 正在流式回复：

```
┌─────────────────────────────────────────────────────┐
│ Ruoxue                                    [● 已连接] │
├─────────────────────────────────────────────────────┤
│                                                     │
│  ┌──────────────────────────┐                       │
│  │ 你好，今天天气怎么样？     │  14:23               │ ← 用户消息 (右对齐)
│  └──────────────────────────┘                       │
│                                                     │
│  14:23  ┌────────────────────────┐                  │
│         │ 今天天气不错！温度...    │                  │ ← AI 回复 (左对齐，已完成)
│         └────────────────────────┘                  │
│                                                     │
│  ┌──────────────────────┐                           │
│  │ 帮我查一下明天       │  14:24                    │ ← 用户消息
│  └──────────────────────┘                           │
│                                                     │
│  14:24  ┌────────────────────────┐                  │
│         │ 好的，明天北京天气晴   █│                  │ ← AI 正在流式回复，▉ 为闪烁光标
│         └────────────────────────┘                  │
│                                                     │
├─────────────────────────────────────────────────────┤
│ [你好] [天气] [你能做什么]                            │
├─────────────────────────────────────────────────────┤
│ [                                    ] [发送(禁用)] │ ← 发送中时按钮禁用
└─────────────────────────────────────────────────────┘
```

**流式打字细节：**
```
逐字显示效果:
  0ms    ""
  50ms   "好"
  100ms  "好的"
  150ms  "好的，"
  200ms  "好的，明"
  ...
  最后    "好的，明天北京天气晴朗，温度 25-32 度。"
                                    ▉  <- 闪烁光标，收到 done 后消失
```

## 五、移动端 (<768px)

```
┌───────────────────────────────┐
│ Ruoxue               [●]     │ ← Header (48px)
├───────────────────────────────┤
│                               │
│  ┌──────────────┐             │
│  │ 你好         │  14:23     │
│  └──────────────┘             │
│                               │
│  14:23  ┌──────────┐          │
│         │ 你好！    │          │
│         └──────────┘          │
│                               │
├───────────────────────────────┤
│ [你好] [天气]                  │ ← 快捷回复可横向滚动
├───────────────────────────────┤
│ [输入...____________] [发送]  │ ← InputBar (min=52px)
└───────────────────────────────┘
```

**PC vs 移动端差异：**

| 元素 | PC | 移动端 |
|------|-----|--------|
| 整体宽度 | 全屏 | 全屏 |
| Header 高度 | 56px | 48px |
| 快捷回复 | 显示全部 | 横向滚动，最多显示 2 个 |
| 输入框高度 | min 60px | min 52px |
| 消息气泡最大宽 | 70% | 85% |
| 空状态图标 | 完整 | 缩小 |

---

## 六、交互对照表

| 操作 | PC | 移动端 |
|------|-----|--------|
| 发送消息 | 回车键 / 点击发送 | 点击发送 |
| 换行输入 | Shift + 回车 | 换行键 |
| 停止生成 | 点击发送按钮(变停止) | 点击发送按钮(变停止) |
| 点击快捷回复 | 填入输入框并自动发送 | 填入输入框并自动发送 |
| 点击重试 | 重新发送上一条 | 重新发送上一条 |

## 七、CSS 关键变量

```css
:root {
  --header-h: 56px;
  --input-min-h: 60px;
  --quick-reply-h: 36px;
  --bubble-max-w: 70%;
  --msg-gap: 16px;
}

@media (max-width: 767px) {
  :root {
    --header-h: 48px;
    --input-min-h: 52px;
    --bubble-max-w: 85%;
  }
}
```

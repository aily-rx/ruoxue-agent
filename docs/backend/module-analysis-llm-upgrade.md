# Ruoxue — LLM 选型分析

> 版本: v1.0 | 日期: 2026-07-24

---

## LLM 方案对比

| 模型 | 类型 | 中文能力 | 成本 | 部署 |
|------|------|---------|------|------|
| DeepSeek-V3 | 云端 | 优秀 | 低 | API |
| Qwen2.5-7B | 本地 (Ollama) | 良好 | 免费 | 需要 6GB+ VRAM |
| GPT-4o | 云端 | 优秀 | 高 | API |
| Claude 3.5 | 云端 | 良好 | 中 | API |

## 推荐策略

- **日常对话**: Ollama + Qwen2.5-7B (本地，免费)
- **复杂任务/工具调用**: DeepSeek-V3 (云端，低成本)
- **未来可切换**: LangChain 统一接口，切换模型只需改配置

# Engineering Skills

Code-focused skills for daily development work.

## Model-invoked (自动触发)

- **[read-before-code](./read-before-code/SKILL.md)** — 编码前强制读取数据源/配置/Sample，消除"我以为"假设
- **[prototype-first](./prototype-first/SKILL.md)** — 原型先行，覆盖6种页面状态，ASCII 布局标注三层信息
- **[defensive-output](./defensive-output/SKILL.md)** — LLM输出三层过滤，不被下游系统信任
- **[diagnose-bugs](./diagnose-bugs/SKILL.md)** — 结构化bug诊断：复现→外因排除→逐层验证→对照参考→修复
- **[implement](./implement/SKILL.md)** — 按依赖方向从下往上实现，写完一个模块测一个
- **[code-review](./code-review/SKILL.md)** — 双轴审查（规范+实现）+ 7个反模式清单
- **[tdd](./tdd/SKILL.md)** — 测试驱动开发，red-green-refactor循环
- **[codebase-design](./codebase-design/SKILL.md)** — 深模块设计，接口与实现分离
